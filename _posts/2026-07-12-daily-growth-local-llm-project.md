## 🔗 1. 기존 프로젝트 GitHub 연동

회사에서 만들던 **RUN-Project**(러닝대회 정보 사이트, Next.js + Prisma + SQLite)를 개인 GitHub 저장소에서 새 컴퓨터로 내려받아 개발을 이어갈 수 있도록 세팅했습니다.

- SSH 키 생성 후 GitHub 계정에 공개키 등록 → `git clone`
- `nvm`으로 Node.js 설치 (Homebrew가 없는 환경이라 nvm 공식 스크립트로 진행)
- `npm install` → `.env` 구성 → `npx prisma migrate dev`로 로컬 SQLite DB 생성
- `npm run scrape`로 실제 대회 데이터 수집까지 확인

이 프로젝트는 이미 "로컬 SQLite DB는 git에 올리지 않고, 코드만 동기화 + 각 위치에서 직접 `scrape`로 DB 채우기" 워크플로우가 README에 문서화되어 있었어서, 그대로 따라가며 실제로 커밋 → 푸시 → 원격 저장소 반영까지 커밋 해시를 비교하며 검증했습니다.

## 🤖 2. 새 프로젝트: Daily Growth

이번엔 새로운 아이디어로 프로젝트를 하나 더 만들었습니다. 매일 뉴스와 영어 단어를 자동으로 모아주는 **자기계발 사이트**입니다.

### 데이터 소스
| 소스 | 용도 |
|---|---|
| 네이버 뉴스 검색 API | 자기계발/커리어/재테크 관련 국내 뉴스 수집 |
| [VOA Learning English](https://learningenglish.voanews.com) | 영어 학습자용 텍스트 기사 + 자체 제공 "Words in This Story" 단어 목록 |

VOA 기사는 크롤링 시 ToS 부담 없는 공개 RSS/HTML 구조를 가지고 있고, 무엇보다 기사 안에 이미 단어와 뜻이 정리되어 있어서(`Words in This Story` 섹션) 파싱만 잘 하면 꽤 정확한 단어 데이터를 뽑아낼 수 있었습니다.

### 로컬 LLM 역할 분담
맥미니에 Ollama로 설치해둔 로컬 모델 두 개를 용도에 따라 나눠 썼습니다.

- **`gemma2:9b`** — 크롤링 후 요약, 단어 뜻/예문 생성 같은 구조화된 작업
- **`llama3:latest`** — 사이트 내 "AI 튜터에게 물어보기" 대화형 기능

같은 컴퓨터(맥미니)에서 Next.js 앱과 Ollama가 함께 돌아가고 있다는 걸 뒤늦게 알아채고 나서(`hostname` 확인하다 발견 😅) `localhost:11434`로 바로 붙일 수 있어서 네트워크 설정 없이 훨씬 간단해졌습니다.

### 결과
- VOA 기사 24건, 단어 150개 자동 수집 + 한글 번역/예문 생성
- 네이버 뉴스 78건 수집 + gemma2 요약
- `/chat` 페이지에서 오늘의 단어/기사를 컨텍스트로 llama3와 대화 가능

## 🐛 오늘의 트러블슈팅

### 1) launchd가 파일 접근을 거부함
매일 아침 7시에 자동으로 `npm run scrape`가 돌도록 `launchd`로 등록했는데, `Operation not permitted` 에러가 발생했습니다. 원인은 macOS가 `Desktop`/`Documents`/`Downloads` 폴더를 백그라운드 프로세스로부터 특별히 보호하기 때문 — 터미널에서 직접 실행할 땐 터미널 앱 자체가 이미 권한을 갖고 있어서 문제가 없었던 것뿐이었습니다. 프로젝트를 홈 디렉토리 바로 아래(`~/daily-growth`)로 옮기는 걸로 깔끔하게 해결했습니다.

### 2) LLM이 JSON을 이상하게 뱉음
단어 번역용 프롬프트에서 LLM 응답을 JSON으로 파싱하는데, `\{[\s\S]*\}`(greedy) 정규식 때문에 첫 `{`부터 마지막 `}`까지 통째로 잡아버려 파싱이 깨지는 케이스가 있었습니다. `\{[\s\S]*?\}`(lazy)로 바꿔서 해결.

### 3) 한국어로 답하라 했는데 영어로 답함
대화형 기능 첫 테스트에서 llama3가 "한국어로 답해줘"라는 지시를 무시하고 영어로 답변했습니다. 프롬프트 앞뒤로 "반드시 한국어로만" 지시를 반복 강조하니 이후로는 안정적으로 한국어 답변.

### 4) 네이버 API 응답의 HTML 엔티티
네이버 뉴스 API가 제목에 `&quot;` 같은 HTML 엔티티를 포함해서 내려주는데, 태그만 제거하고 엔티티 디코딩을 안 해서 화면에 `&quot;`가 그대로 노출되는 버그가 있었습니다. 디코딩 로직 추가로 수정.
